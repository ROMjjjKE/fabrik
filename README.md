# ООО «ФабрикСтайл» — модульные кухни и шкафы

Семь страниц: index, katalog, konstruktor, raboty, o-kompanii, kontakty, politika.

Арт-дирекция: чертёжная. Бумага #FAFAF6, чернильный #0F100E, жёлтая заливка модулей #F5C518. Unbounded 700 в заголовках, Golos Text в тексте, PT Mono в размерах.

Главный интерактив: конструктор раскладки. Ползунок задаёт ширину стены, модули добавляются и убираются, справа рисуется разрез стены по той же сетке (48 колонок на всю стену), считается занятая ширина по рядам. Верхний и нижний ряд считаются отдельно, потому что висят друг над другом. Раскладка отправляется в WhatsApp одним сообщением.

Фотографии кухонь — из трёх присланных заказчиком снимков, водяной знак обрезан снизу. Остальные изображения сгенерированы и подлежат замене на реальные.

Критический CSS встроен в style до ссылки на assets/css/style.v1.css.

## Перед запуском
1. УНП и юридический адрес. В подвале стоит «уточняется».
2. Реальные фото вместо сгенерированных (mod1, mod2, pack, shkaf).
3. Подтвердить размеры модулей 400/600/800 и высоты 720/2160: взяты как типовые, фабрика должна подтвердить.
4. Подтвердить условия доставки по областям, сроки, входит ли столешница.
